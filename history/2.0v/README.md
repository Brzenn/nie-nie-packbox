# 成贤资料库 · 2.0v

感谢 **捏捏学长** 整理并开放资料。  
原站：<https://openlist.truraly.fun/成贤学院课程攻略共享计划/资料库>

本地服务版：资料直接写入本机 `课程资源/`，可打包成单机程序使用。

## 功能

- `start.bat` / `python server.py` 启动，浏览器访问本地界面
- 课程列表：字母序、搜索
- 下载到 `课程资源/`，目录结构与资料库一致
- 检查更新：按文件名对比，只下新增，不删本地
- 本地课程资源：浏览已下载课程与文件
- 按钮：文件夹「打开」/ 文件「查看」；本地课「更新」+「打开本地文件夹」
- 网页预览：Markdown、图片、PDF、视频、文本
- Word / PPT / Excel 等：系统默认程序打开
