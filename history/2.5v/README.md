2.4v 基础上完善离线使用，是目前推荐版本。

## 功能

- 与 2.4v 一致（本地服务、下载、更新、存储位置、预览、原链跳转等）
- **离线**：启动服务后无网络也能浏览已下载资料
- 在线失败自动回退本地目录；远程请求短超时，不卡死
- 启动自动探测本机服务端口 8765–8775
