# 捏捏资料打包盒 · 1.1.2v（手机版）

成贤学院课程资料检索 / 打包下载小工具 —— **手机网页版**。

**解决痛点：** 原站一次只能点一个文件，手机上更难下。本页面每行右侧直接「下载」，整门课 / 整个文件夹一键打 ZIP，单文件单下。

资料来源：[成贤学院课程攻略共享计划](https://openlist.truraly.fun/%E6%88%90%E8%B4%A4%E5%AD%A6%E9%99%A2%E8%AF%BE%E7%A8%8B%E6%94%BB%E7%95%A5%E5%85%B1%E4%BA%AB%E8%AE%A1%E5%88%92)（感谢捏捏学长整理并开放）

## 功能

- 课程列表：搜索 + 字母序
- **每行右侧「下载」**
  - 课程 → 整门课 ZIP
  - 文件夹 → 整个文件夹 ZIP
  - 文件 → 单文件下载
- 点名称进入下一级目录
- **更多**（标题右侧按钮）
  - 捏捏资料库
  - 电脑版 ZIP 下载（强制保存）
  - GitHub（求个 star，谢谢喵~）
- 打包进度可视化
- 移动端适配：大按钮、单列、安全区

---

## 怎么用

1. 打开 <http://47.100.218.19/nienie/>
2. 课程列表：点右侧 **下载** = 整门课 ZIP；点名称进入
3. 目录内：文件夹 **下载** = 该夹 ZIP；文件 **下载** = 单文件
4. 要桌面程序 → 标题旁 **更多** → **电脑版 ZIP 下载**

## 技术说明

| 项 | 说明 |
|----|------|
| 形态 | 纯前端（HTML + CSS + JS） |
| 打包 | 浏览器内 JSZip |
| 数据 | OpenList API 按需拉取 |
| 部署 | 阿里云 Nginx 静态托管 |
| 版本 | **1.1.2v** |

### 文件结构

```text
index.html    入口
styles.css    样式
app.js        列表 / 下载 / 打包
vendor/jszip.min.js
```
