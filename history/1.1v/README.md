# 捏捏资料打包盒 · 1.1.2v（手机版）

成贤学院课程资料检索 / 打包下载小工具 —— **手机网页版**。

**解决痛点：** 原站一次只能点一个文件，手机上更难下。本页面每行右侧直接「下载」，整门课 / 整个文件夹一键打 ZIP，单文件单下。

资料来源：[成贤学院课程攻略共享计划 · 资料库](https://openlist.truraly.fun/成贤学院课程攻略共享计划/资料库)（感谢捏捏学长整理并开放）

## 功能

- 课程列表：搜索 + 字母序
- **每行右侧「下载」**：课程 / 文件夹 = ZIP，文件 = 单下
- 点名称进入下一级
- **更多菜单**：资料库、电脑版 ZIP、GitHub
- 打包进度可视化 · 移动端适配
