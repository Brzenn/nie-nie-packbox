# 捏捏资料打包盒 · 1.1.1v（手机版）

成贤学院课程资料检索 / 打包下载小工具 —— **手机网页版**。

**解决痛点：** 原站一次只能点一个文件，手机上更难下。本页面每行右侧直接「下载」，整门课 / 整个文件夹一键打 ZIP，单文件单下。

资料来源：[成贤学院课程攻略共享计划 · 资料库](https://openlist.truraly.fun/成贤学院课程攻略共享计划/资料库)（感谢捏捏学长整理并开放）

---

## 访问方式

本项目为 **服务器部署版**，无需下载安装包。

| 方式 | 说明 |
|------|------|
| **在线访问** | **<http://47.100.218.19/nienie/>**（手机 / 电脑浏览器直接打开） |
| 本地预览 | 用浏览器打开本目录 [`index.html`](index.html) |

> 纯前端静态页，已部署至阿里云 Nginx。

---

## 功能

- 课程列表：搜索 + 字母序
- **每行右侧「下载」按钮**
  - 课程 → 整门课打包 ZIP
  - 文件夹 → 整个文件夹打包 ZIP
  - 文件 → 单文件下载
- 点名称可进入下一级目录
- 打包进度可视化
- 移动端适配：大按钮、单列布局、安全区

---

## 怎么用

1. 打开 <http://47.100.218.19/nienie/>（或本地 `index.html`）
2. 课程列表：点右侧 **下载** = 整门课 ZIP；点名称进入目录
3. 目录内：文件夹右侧 **下载** = 该夹 ZIP；文件右侧 **下载** = 单个文件
4. ZIP 保留原目录结构，手机解压后即可查看

## 技术说明

| 项 | 说明 |
|----|------|
| 形态 | 纯前端（HTML + CSS + JS） |
| 打包 | 浏览器内 JSZip 生成 ZIP |
| 数据 | OpenList API 按需拉取 |
| 依赖 | 仅 `vendor/jszip.min.js` |
| 版本 | **1.1.1v**（1.1v 修复整包下载容错与路径） |

### 文件结构

```text
index.html    入口
styles.css    样式
app.js        列表 / 下载 / 打包逻辑
vendor/jszip.min.js
```
