# 捏捏资料打包盒

成贤学院课程资料本地检索 / 下载 / 浏览小工具。

**解决痛点：** 原站一次只能点一个文件，资料一多就下到崩溃。本工具支持按课程**一键打包下载 / 批量更新**，目录结构与线上一致，下完还能离线看。

## 2.5v 怎么用

1. 下载上方 **`捏捏资料打包盒-2.5v.rar`**，解压到任意文件夹  
2. 双击 **`捏捏资料打包盒-2.5v.exe`**  
3. 浏览器会自动打开本地页面（一般为 `http://127.0.0.1:8765`）  
4. 在「在线资料库」浏览课程，点 **打包下载 / 更新**  
5. 下载后可在「本地课程资源」离线浏览（Markdown、图片、PDF、视频等）

**环境**

- Windows 10 / 11  
- 推荐 Chrome / Edge  
- 无需安装 Python（2.5v 为独立程序）

---

## 功能（2.5v）

- 课程列表：字母序 + 搜索
- 打包下载到本地，目录结构与线上资料库一致
- 检查更新：只下新增，不删本地
- 本地课程：更新 / 打开文件夹 / 文件预览
- 网页预览：Markdown、图片、PDF、视频、文本
- Word / PPT / Excel 等：用系统默认程序打开
- **离线可用**：已下载资料无网络也能浏览
- 更改存储位置并整库迁移
